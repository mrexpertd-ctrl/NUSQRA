# NUSQRA mobile builds

Capacitor packages the NUSQRA React frontend with its Arabic and English UI and existing Supabase backend. The provisional Android package and iOS bundle ID is `com.nusqra.marketplace`. Native project directories are generated by the preparation script using the pinned packages.

## Build previews

From `nusqra-starter`, install with `npm ci`. Copy `.env.example` to `.env.production.local`, or set both public Supabase environment variables for your intended backend. The preparation script builds the frontend, synchronizes it and registers the app's sign-in callback.

- **Android** — run `npm run mobile:prepare -- android` and open the generated `android` directory in Android Studio, or run `cd android && bash ./gradlew assembleDebug`. Use Java 21 and Android SDK 36.
- **iOS** — run `npm run mobile:prepare -- ios` and open `ios/App/App.xcodeproj` in Xcode 26 or newer. Select an iOS simulator for a local preview.

The **NUSQRA mobile preview builds** workflow produces a debug APK and an unsigned iOS simulator build. Installing on an iPhone or distributing through TestFlight requires an Apple-signed device build. Store builds require release signing and store developer access.

## Verify sign-in and core flows

In Supabase Authentication → URL Configuration, add the exact additional redirect URL `com.nusqra.marketplace://auth/callback`. Google continues to send users to the existing Supabase OAuth callback. Check Google sign-in and email confirmation on the same device that started the flow. Check returning to the app with the app open and from a cold start. Use a test account to verify sign-in, opening a profile, sending a proposal or posting a job, and messaging another test account.

Before App Store submission, review the iOS login options against Apple guideline 4.8, publish the required privacy disclosures, and verify account deletion and marketplace reporting inside the app.
